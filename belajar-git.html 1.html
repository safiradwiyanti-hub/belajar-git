Belajar GIT 30 menit siap

  • 1. buat folder baru
  • 2. masuk ke terminal dan ketik git init
  • 3. buat perubahan di file
  • 4. git add .
  • 5. git commit -m "pesan commit"
  • 6. buat repository di github
  • 7. git branch -M main
  • 8. git remote add origin https://github.com/username/nama-repo.git
  • 9. git push -u origin main
  • 10. next step: 3,4,5,9
  • 11. jika sudah selesai, silahkan buka repository di github dan lihat perubahan
